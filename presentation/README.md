# Presentation

The 7-minute talk for NASA Space Apps 2026, then 3 minutes of questions.

**Watch it online:** https://catoooos21.github.io/Weather-Witness/presentation/ (the 7 slides with the opening video; the files are in `web/public/presentation/`).

| File | What it is |
|---|---|
| `script.md` | The full script, slide by slide, with timings and the sources of every number |
| `parts/` | One script per speaker: Manayer, Bashayer, Kawthar, Ahmed, Mohammed |
| `judge-questions.md` | Short answers if the judges ask about the stack or the prediction |
| `Weather-Witness-demo.pdf` | The project demo for the submission: the 7 slides as a PDF |
| `Weather-Witness-no-video.pptx` | The 7 slides, with a still picture on slide 2 instead of the video |
| `slides/` | A picture of each slide |
| `hook-video.mp4` | The 30-second video for the submission |
| `make_video.py`, `make_slide_video.py` | The scripts that made the videos |

The deck we present from, and its 30-second slide video, are kept off GitHub because they include a news interview clip that is shown only in the live presentation. The online version uses a 23-second cut of the same video without that clip: after the lighter, a caption carries the line Manayer says live.
